# «тихо» — PWA и синхронизация

## Что внутри

- `index.html` — финансовый трекер;
- `manifest.webmanifest` и `sw.js` — установка на главный экран и офлайн-кэш;
- `worker.js` — бесплатный Cloudflare Worker для зашифрованной синхронизации;
- `wrangler.toml` — заготовка конфигурации Worker;
- `icons/` — иконки приложения.

## Важно о защите

HTML не содержит Telegram-токен. Данные шифруются в браузере с AES-GCM до отправки. Worker видит только зашифрованную копию. Фраза шифрования хранится только на устройстве, поэтому её нужно записать отдельно.

## Бесплатная публикация PWA

1. Создайте репозиторий на GitHub и загрузите содержимое этой папки.
2. Включите GitHub Pages для ветки `main`.
3. Откройте получившийся `https://...github.io/...` адрес в Safari на iPhone.
4. Нажмите «Поделиться» → «На экран Домой» → включите «Открыть как веб-приложение» → «Добавить».

## Подключение синхронизации

1. В Cloudflare создайте KV namespace и подставьте его ID вместо `REPLACE_WITH_KV_NAMESPACE_ID` в `wrangler.toml`.
2. Установите Wrangler и выполните `npx wrangler login`, затем `npx wrangler deploy`.
3. Добавьте секрет `SYNC_ACCESS_KEY` командой `npx wrangler secret put SYNC_ACCESS_KEY`. Это длинный случайный ключ.
4. Необязательно: добавьте `BOT_TOKEN` и `TELEGRAM_CHAT_ID`, чтобы получать в Telegram уведомление после каждой синхронизации. Токен добавляется только как секрет Worker.
5. В приложении откройте «Настройки» → «Синхронизация», укажите URL Worker, ключ доступа и отдельную фразу шифрования. Нажмите «Сохранить в облако».

Не вставляйте токен бота в `index.html` и не публикуйте его в GitHub.
